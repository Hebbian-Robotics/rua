# Viewer dependency license files

The npm packages below do not include their complete license files. These
copies come from the exact upstream release tags used in `pnpm-lock.yaml`:

- [`@bufbuild/protobuf` 1.10.1](https://github.com/bufbuild/protobuf-es/tree/v1.10.1):
  the repository's Apache license and the Google BSD notice from
  `packages/protobuf/src/google/varint.ts`.
- [`@react-three/fiber` 9.8.2](https://github.com/pmndrs/react-three-fiber/blob/v9.8.2/LICENSE):
  the repository license from the upstream release tag.
- [`urdf-loader` 0.13.1](https://github.com/gkjohnson/urdf-loaders/tree/v0.13.1):
  the repository's Apache license.

The wheel build copies the other production viewer dependencies' license and
notice files from their installed packages.
