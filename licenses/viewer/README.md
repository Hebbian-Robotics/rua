correspond to the package versions in `pnpm-lock.yaml`.

  the repository's Apache license and the Google BSD notice from
  `packages/protobuf/src/google/varint.ts`.

  the [MediaPipe Apache license](https://github.com/google-ai-edge/mediapipe/blob/3fa8974c47cd0297c74ed6c424e0406f5054796f/LICENSE)
  from the upstream revision on the npm release date.

  the repository license from the upstream release tag.

  the repository's Apache license from the upstream release tag.
